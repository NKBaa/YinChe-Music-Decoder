# 音澈 🎵

> 一个清爽、专注的 Windows 音乐解码工具。

音澈统一支持网易云音乐、酷狗音乐和 QQ 音乐的加密下载文件。批量导入，一键处理：自动模式只解密并保留原格式，选择 MP3 / FLAC 时再按需转码。✨

## ✨ 功能亮点

- 🎧 **多平台识别**：网易云音乐、酷狗音乐、QQ 音乐、酷我音乐、喜马拉雅、咪咕音乐和虾米历史格式集中识别
- 📦 **批量导入导出**：支持文件、文件夹和拖放导入
- 🗂️ **智能整理**：递归扫描子目录，并可保留原目录结构
- ⚡ **多线程解码**：1–32 线程自由调节，按内存预算控制实际并发
- 🧠 **内存优先管线**：先在内存中解密，再通过单一通道安全写盘
- 🏷️ **自动补全信息**：写入歌名、歌手、专辑、歌词与封面
- 🔍 **真实格式识别**：根据解密后的文件头识别 MP3、FLAC、OGG 等格式
- 🛡️ **安全落盘**：使用临时文件、磁盘刷新和原子重命名，降低文件损坏风险

## 🎼 支持范围

音澈当前可识别的平台包括：网易云音乐 ☁️、酷狗音乐 🐶、QQ 音乐 🐧、酷我音乐 🎶、喜马拉雅 📻、咪咕音乐 📱，以及虾米历史格式 🦐。具体能否纯离线解码，请以格式支持矩阵中的状态为准。

| 来源 | 输入格式 | 解密方式 | 可能的原始格式 |
| --- | --- | --- | --- |
| 网易云音乐 | `.ncm` | 本地流式解密 | MP3 / FLAC |
| 酷狗音乐 | `.kgm` `.kgma` `.vpr` | 本地流式解密 | MP3 / FLAC 等 |
| QQ 音乐 | `.mflac` `.mgg` | 调用运行中的 QQ 音乐解密组件 | FLAC / OGG |

### 📊 格式支持矩阵

| 平台 | 格式 | 状态 | 是否需要官方客户端 |
| --- | --- | --- | --- |
| 网易云音乐 | NCM | ✅ 已验证 | 否 |
| 酷狗音乐 | KGM / KGMA / VPR | ✅ 已验证 | 否 |
| QQ 音乐 | MFLAC / MGG（当前客户端接口） | ✅ 已验证 | 是，需要已登录 QQ 音乐 |
| QQ 音乐 | QMC0–QMC8 / QMCFLAC / QMCOGG / TKM | 🧪 已识别，实验性 | 否（算法待样本验证） |
| QQ 音乐 | MFLAC0 / MFLACH / MGG0 / MGG1 / MGGL | 🧪 QTag/STag/MusicEx 可识别 | 视格式而定 |
| 酷我音乐 | KWM | 🧪 已登记，未验证 | 否 |
| 喜马拉雅 | X2M / X3M | 🧪 已登记，未验证 | 否 |
| 咪咕音乐 | MG3D | 🧪 已登记，未验证 | 否 |
| 酷狗音乐 | KGG / KGM v5 | 🧪 已登记，未验证 | 可能需要 |

> 🧭 “已识别”不等于“已解码”。缺少可靠算法或测试样本的格式会明确提示未验证，不会伪造成功。

> [!IMPORTANT]
> `自动保留原格式` 只解密、不转码；选择 `仅 MP3` 或 `仅 FLAC` 时，会使用 FFmpeg 将解密结果转换为目标格式。

- `自动保留原格式`：根据解密后的文件头命名为真实格式。
- `仅输出 MP3`：将所有已解密音频转换为 MP3。
- `仅输出 FLAC`：将所有已解密音频转换为 FLAC。

转码模式需要系统可找到 `ffmpeg.exe`。程序不会把文件内容和扩展名混淆；转换失败会保留原文件并显示原因。

界面中的 **码率** 控制 MP3 输出（自动、128k、192k、256k、320k）；**位深** 控制 FLAC 输出（自动、16 bit、24 bit、32 bit）。这些选项只在目标格式与源格式不同时生效。

## 🖼️ 歌词、封面与标签

解码完成后，程序会在不重新编码音频的前提下写入歌曲标签：

- NCM 优先使用文件内嵌的歌名、歌手、专辑和封面。
- 歌词优先读取元数据，随后查找加密文件旁的同名 LRC 文件。
- 封面缺失时会查找同名图片以及目录中的 cover.jpg、folder.jpg 等文件。
- 标签写入失败不会删除已经成功解码的音频，状态栏会显示原因。

## 🗂️ 文件夹选项

- **递归扫描**：添加文件夹时，继续搜索它的全部子文件夹。
- **保留目录结构**：输出时复刻导入文件夹内部的相对目录层级。

界面中的提示文字会同步解释这两个选项，使用时无需猜测。💡

## 🚀 快速使用

1. 点击“添加文件”或“添加文件夹”，也可以直接把文件拖进窗口。
2. 选择输出目录、输出格式和线程数。
3. 点击“开始解码”，等待成功动效出现。✅
4. 点击输出路径旁的“打开”，直接查看解码结果。

> [!NOTE]
> 处理 QQ 音乐文件前，需要启动并登录 QQ 音乐 Windows 客户端。账号必须拥有对应文件的合法下载权限。QQ 音乐更新后，其导出接口可能发生变化。

## ⚡ 性能与写盘策略

批处理支持 1–32 个自定义并行线程。默认使用最多 4 个线程；机械硬盘建议 2–4 个，SSD 通常建议 4–8 个。线程越多不一定越快，20 线程常会受单盘读写吞吐限制。NCM 和 KGM 文件会并行处理，QQ 音乐客户端接口则为保证稳定性自动串行调用。

每个文件会先在内存中完成解密，再通过单一写盘通道分块写入临时文件，刷新磁盘后原子生成最终文件。程序按约 1 GiB 内存预算自动限制实际并发数，避免大量无损文件同时驻留造成内存耗尽。文件写入完成前应用拒绝关闭，“停止”只取消尚未完成解密的任务，不会中断已经开始的磁盘写入。

## 🛠️ 开发与构建

需要 Python 3.12：

```powershell
python -m pip install -r requirements.txt
python app.py
```

构建单文件 Windows 程序：

```powershell
.\build.ps1
```

产物位于 `dist\音澈-音乐解码.exe`。🎉

## 🔬 自动识别与降级

音澈内部按“文件 → 格式检测 → 平台/代际判断 → 解码器 → 元数据 → 输出”的顺序处理。缓存位于 `%LOCALAPPDATA%\YinChe\key-cache.json`，读取或写入失败不会影响程序启动。🔐

单个文件失败不会终止批量任务。普通界面不会要求用户填写 Cookie、EKey、authst 或数据库路径。
